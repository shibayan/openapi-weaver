# Security Policy

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues.

Use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is not available, contact the repository owner using the contact information published on GitHub and include enough detail to reproduce and assess the issue.

Please include:

- A clear description of the issue
- Affected package version or commit
- Reproduction steps or a proof of concept
- Impact assessment, if known

You can expect an initial response as soon as practical. After validation, a fix will be prepared and released before full public disclosure when possible.

## Supported Versions

Security fixes are provided for the latest released package version and the current `master` branch.

## Non-Security Bugs

For ordinary defects, feature requests, and usage questions, open a normal GitHub issue.
